# 16 — AI Players

## Overview

AI controls 6 Great Powers and 16 Minor Nations in single-player. The AI must manage
all game systems: economy, diplomacy, military, and trade. Minor Nations have simpler
decision-making (mainly trade and diplomacy). AI quality is critical for a superlative
experience.

## Checklist

### AI Architecture — Rust Engine + Lua Strategy Scripts
- [x] `AiDecisionMaker` trait (Rust) — produces orders for all 5 game phases
- [ ] **Rust engine** handles: valid move enumeration, utility scoring framework, tactical combat decisions (performance-critical, many units × many options)
- [ ] **Lua scripts** handle: high-level strategy weighting, personality flavor, diplomatic preferences, tech research priorities
  - [ ] `scripts/ai/balanced.lua` — default personality
  - [ ] `scripts/ai/aggressive.lua` — prioritizes military expansion, higher war willingness
  - [ ] `scripts/ai/diplomatic.lua` — prioritizes trade and alliances, avoids war
  - [ ] `scripts/ai/economic.lua` — prioritizes production efficiency and tech research
  - [ ] Each script exports `evaluate_priorities(game_state)` → returns weighted goal table
  - [ ] Rust engine calls Lua for strategic direction, then selects/executes best actions in Rust
- [ ] AI state: persistent per-nation memory of goals, threats, opportunities (Rust struct, read-only view exposed to Lua)
- [x] AI difficulty scaling: Normal = fair; Hard = minor bonuses; NOI = significant bonuses (tuning values in Lua)
- [x] Separate AI logic for Great Powers vs. Minor Nations
- [ ] Modders can add new AI personalities by dropping a Lua script into `scripts/ai/`
- [x] Unit tests: AI produces valid orders for each game phase
- [ ] Unit tests: each default Lua personality script loads and returns valid priority weights

### Great Power AI — Economic Management
- [ ] **Civilian deployment**: assign specialists to highest-value tiles
  - [ ] Prioritize: unprospected tiles, unimproved high-value terrain, infrastructure gaps
- [ ] **Industry orders**: allocate resources to maximize production value
  - [ ] Balance raw material processing vs. finished goods
  - [ ] Prioritize arms production when military expansion needed
- [ ] **Transport**: allocate freight capacity to most valuable resources first
  - [x] Build freight cars when bottlenecked
- [x] **Technology research**: prioritize techs that unlock the most valuable improvements
  - [ ] Early: resource improvement techs (Seed Drill, Cotton Gin, etc.)
  - [ ] Mid: military techs for defense/expansion
  - [ ] Late: advanced military and economic techs
- [x] **Building expansion**: expand mills/factories when production bottlenecked
- [x] **Worker training**: maintain pipeline of untrained → trained → expert workers
- [x] Unit tests: AI economic decisions produce viable economies over 50 turns

### Great Power AI — Diplomacy
- [ ] **Trade Consulate / Embassy building**: prioritize Minor Nations with valuable resources
- [ ] **Treaty management**: propose pacts with nearby Minor Nations; alliances with non-threatening Great Powers
- [x] **War declaration**: assess military strength vs. target; only declare when confident
- [ ] **Alliance honoring**: generally honor alliances (breaking damages standing)
- [ ] **Cash grants / subsidies**: invest in Minor Nations that are strategically important
- [ ] **Council of Governors**: track vote count; prioritize actions that gain governors
- [ ] Unit tests: AI diplomatic decisions are consistent with goals

### Great Power AI — Military
- [x] **Force composition**: balance infantry, cavalry, and artillery for effective armies
- [x] **Defense**: station units in vulnerable border provinces
- [x] **Offense**: assemble attack force, target weakest accessible enemy province
- [ ] **Naval**: build warships for sea control; merchant ships for trade capacity
- [ ] **Beachhead**: evaluate overseas targets; execute amphibious invasions
- [x] **Unit upgrades**: upgrade units as techs become available
- [ ] **General utilization**: attach Generals to main armies for initiative bonus
- [ ] Unit tests: AI military decisions produce reasonable force compositions

### Great Power AI — Tactical Combat
- [ ] **Unit positioning**: deploy units based on role (cavalry front for counter-attacks, artillery rear)
- [ ] **Targeting priority**: focus fire on weakest/most dangerous enemy units
- [ ] **Sapper usage**: direct sappers toward forts; use "S" equivalent to skip non-sappers
- [ ] **Retreat decision**: retreat when battle is clearly lost to preserve units
- [ ] **Fort assault**: use heavy artillery to destroy fort sections before advancing
- [ ] Unit tests: AI tactical decisions produce reasonable battle outcomes

### Minor Nation AI
- [ ] Simpler decision-making than Great Powers
- [ ] **Trade**: accept best trade offers; prefer partners with higher relationship scores
- [ ] **Diplomacy**: accept pacts/voluntary incorporation based on relationship thresholds
- [ ] **Defense**: use garrison (Militia) for defense; never initiate wars
- [ ] **Request help**: when attacked, request help from pact partners
- [ ] Unit tests: Minor Nation AI responds correctly to trade offers and attacks

### AI Personalities (Stretch Goal)
- [ ] **Aggressive** — prioritizes military expansion, higher war willingness
- [ ] **Diplomatic** — prioritizes trade and alliances, avoids war
- [ ] **Economic** — prioritizes production efficiency and tech research
- [ ] **Balanced** — default personality, adapts to circumstances
- [ ] Personality assigned randomly or per-nation at game start
- [ ] Unit tests: personality affects decision weighting

### AI Difficulty Bonuses
- [ ] **Normal**: no bonuses — AI plays fair
- [ ] **Hard**: AI gets +10% production efficiency, +$1,000 starting cash, slightly better trade prices
- [ ] **NOI**: AI gets +25% production efficiency, +$5,000 starting cash, better trade prices, faster tech availability
- [ ] Bonuses applied transparently through game mechanics (not hidden cheats)
- [ ] Unit tests: difficulty bonuses applied correctly

### Verification Strategy
- [x] **Unit tests**: Run test suite — all AI tests pass
- [x] **Smoke test**: 7-player game (all AI) runs 100 turns without crashes or invalid states
- [ ] **Economic viability**: AI Great Power achieves self-sustaining economy within 20 turns at Normal difficulty
- [ ] **Military competence**: AI successfully conquers at least 1 Minor Nation within 50 turns
- [ ] **Diplomatic sensibility**: AI doesn't declare war on allies; AI honors pacts most of the time
- [ ] **Balance test**: Run 100 full games (all AI) → verify no single nation wins >30% (indicates balance issue)
- [ ] **Performance test**: AI turn generation for all 6 Great Powers + 16 Minor Nations < 2 seconds
- [ ] **Difficulty scaling**: Win rate for human player should decrease as difficulty increases (verify via automated play)
